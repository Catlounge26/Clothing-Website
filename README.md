# Clothing website

A simple two-page shop site (plain HTML and CSS, no build step).

- `index.html` is the main page: the Naturals G-String Brief in Black, fibre breakdown, story, reviews, size guide.
- `fill-your-cart.html` is the "fill your cart" page: add-on basics to reach free shipping.
- `css/style.css` holds the colours and fonts (top of the file).
- `js/cart.js` holds the placeholder prices and the free-shipping minimum (top of the file).

To view it, open `index.html` in any web browser.

Everything marked "placeholder" (prices, fibre percentages, sizes, reviews, photos, brand name) is waiting on real details. There is no real checkout yet.
